# 我的JiuMi 小猫美术规格

这份规格面向角色设定、姿态与逐帧绘制/导出；页面行为见 [ADR-0015](./adr/0015-my-jiumi-page.md)，UI 规则见 [`docs/ui-spec.md`](./ui-spec.md) 的「我的JiuMi」章节。本规格只定方向与交付；最终帧数、逐帧时长与导出尺寸在 [#117](https://github.com/ZLiLiang/JiuMi/issues/117) 定稿后由 [#121](https://github.com/ZLiLiang/JiuMi/issues/121) 冻结。

旧 #106 / #109 的 38 帧写实/AI 方向作废；本规格不再沿用其比例、画布、帧表与体积承诺。

> 2026-11-11 更新：方向改为 **ImageGen 位图**；不交付 SVG/矢量源。ImageGen 原图与导出 PNG 进 git（方向稿放 `docs/images/pet/direction-117/`，#121 最终帧按下方导出目录）；临时试稿、废稿、带水印参考图不进 git。

## 角色

- **原型**：owner 家中的橘猫，但在本规格里是**原创角色**，不是参考图的复刻。保留能一眼认出的特征：橘色虎斑、深橘条纹、白口鼻/胸口/白爪、粉鼻、琥珀眼、耳形与尾巴。
- **比例**：自然猫比例，约 3–3.5 头身；不 chibi、不做大头娃娃，也不把猫几何化/logo 化。四足与尾巴的长度要像真猫。
- **线稿**：粗深棕轮廓（已确认方向稿实测：1024 画布约 6–10px；200 DIP 显示约 1.5–2px；400×400 导出约 3px），圆角连接；轮廓承担主体结构，不是细线装饰。条纹与白色块**不单独描边**，只被身体外轮廓包住。
- **眼睛**：杏仁眼 + 可见上眼睑 + 琥珀虹膜 + 竖瞳 + 白色高光；默认半垂眼、微不爽。避免圆点眼、正面瞪视和过度拟人化的笑。
- **毛色**：主橘 + 深橘虎斑条纹；白口鼻、白胸口、白爪；粉鼻。色板在方向稿里给出 Hex 值，浅色/深色页面使用同一套颜色。
- **质感**：平涂 + 少量柔和暗部；不要毛发细节、渐变、写实光照或 AI 质感。轮廓内部保持干净。
- **背景**：动画帧完全透明；不画墙、地板、房间、底座、光圈或文字。接触阴影由页面绘制，不烘焙进帧。

## 参考素材

- 风格参考为 [#117](https://github.com/ZLiLiang/JiuMi/issues/117) 中 owner 提供的 3 张描边插画。参考图带水印，只作气质、线宽、眼型与配色依据；不描图、不复刻、不进入仓库或最终资产。
- 走路步态参考为 owner 提供的 GIF，提交在 `docs/images/pet/references/walk-reference.gif`；只作步态依据，角色仍为原创。
- 角色方向先出 **1 版**（描边插画）；如确有需要，最多给 2 个微变体（线宽/眼睑），由 owner 选择。不要同时铺开三种画风。
- 眼睛、比例、轮廓、白口鼻/胸口/爪子是「诡异」问题的高风险区，方向稿要优先给脸部特写。

## 姿态与交付（对齐 #117）

先交方向稿，不交最终动画：

1. **趴姿待机（默认）**：头部略抬或搭在前爪上，半垂眼；页面实际尺寸约 200 DIP。
2. **走路**：侧/3-4 视角，逐帧循环方案（#121 最终 33 帧）；头身比自然，不走滑步。
3. **睡着**：闭眼、呼吸、尾巴收拢；`Zzz` 由 UI 叠加，不烘焙。
4. **起身/伸懒腰**：趴 → 走的过渡，2–4 帧方案。
5. **脸部特写**：眼睛/眼睑/口鼻/轮廓，用于确认「诡异」已消失。
6. **浅色与深色背景各看一次**：页面实际尺寸约 200 DIP；透明边缘干净。

交付格式：ImageGen 位图原图 + 页面实际尺寸预览/导出 PNG；不交付 SVG/矢量源。ImageGen 原图与导出 PNG 进 git（方向稿放 `docs/images/pet/direction-117/`）；临时试稿、废稿、带水印参考图不进 git。最终逐帧资源不在 #117，由 #121 交付。

## 页面 v1 的状态与帧

页面模式的动画状态：

| 状态 | 画面要求 | 帧数/时长 |
| --- | --- | --- |
| 趴姿待机（`LyingIdle`） | 趴姿呼吸 + 尾巴轻摆；循环；脚底不滑动 | 2 帧 · 1500 ms/帧 · 循环 |
| 眨眼（`Blink`） | 半闭/闭/睁；身体中性；只改眼睛 | 3 帧 · 80 ms/帧 · 一次性 |
| 点击反应（`React`） | 竖耳、睁眼、轻微弹起；结束回 `LyingIdle` | 2 帧 · 120 ms/帧 · 一次性 |
| 拖拽（`Drag`） | 被轻轻拎起的悬垂姿势；身体略拉长、四肢自然下垂，不表现疼痛/挣扎 | 2 帧 · 400 ms/帧 · 循环 |
| 入睡（`SleepIn`） | 从趴/坐到睡姿的过渡；不循环 | 3 帧 · 150 ms/帧 · 一次性 |
| 睡眠（`Sleep`） | 闭眼慢呼吸；循环；`Zzz` 由 UI 叠加 | 2 帧 · 2000 ms/帧 · 循环 |
| 醒来（`Wake`） | 睁眼/起身；回 `LyingIdle` | 3 帧 · 150 ms/帧 · 一次性 |
| 起身/伸懒腰（`Stretch`） | 趴 → 走的过渡；不循环 | 4 帧 · 120 ms/帧 · 一次性 |
| 走路（`Walk`） | 侧/3-4 走路循环；一个方向，另一方向水平镜像；步幅与页面内速度匹配，不滑步 | 33 帧 · 26 ms/帧（约 38.5 fps）· 循环 |

- **帧数与时长已由 #121 冻结**（见上表）；`MyJiuMiAnimationCatalog` 按此表实现。
- 走路按 owner 提供的 GIF 步态参考生成 5 秒视频（固定机位、原地走），再抽取 33 帧；视频原始约 1.1 s/循环，按参考 GIF 约 0.845 s/循环重定时为 26 ms/帧（约 38.5 fps）；左右腿交替。
- 走路帧按固定缩放（240/386）与固定锚点导出，不做逐帧缩放；视频本身保证帧间尺寸/头身比一致。
- 视频生成提示词与后续跳跃/趴下/起身的复用模板见 [docs/pet-video-prompts.md](./pet-video-prompts.md)。
- 爱心与 `Zzz` 是 UI 矢量元素，**不要烘焙进帧**。
- 眨眼只在 `LyingIdle` 触发；`React`/`Drag`/`Sleep` 中不画眨眼。
- 走路帧按页面内位移速度匹配；按当前步幅约 103 DIP/s（#120 实机微调），自主闲逛与召唤共用一个循环，方向靠水平镜像，不单独画反方向。
- 所有帧的猫必须像同一只猫：同一比例、同一线宽、同一调色板、同一眼型。

## 画布与对齐

- 同一状态、同一画布尺寸；已冻结为 200 DIP 显示、400×400 导出（2×）。
- 所有帧的脚底/身体最低点贴画布底边（400×400 画布上 y=399）；猫的水平中心对齐画布中心 x=200。页面以帧底边对齐地板线。尾巴、耳朵、爪子可超出中心线，但不得出画布。
- `Sleep` 可以更宽、更低，但基线不变；不要为睡着单独换画布。
- 导出的透明边缘不得有黑边/白边；线稿边缘用直通 alpha，不做半透明发光或柔和外扩。
- 最终帧必须从已确认方向稿抠图后透明导出：抠图边缘 defringe 到描边色，不得把方向稿底色（约 `#F3EFEA`）烘焙进帧；先用 1 帧在浅/深色 200 DIP 下验证无白边/黑边，再批量出帧。
- **不烘焙接触阴影**：页面绘制椭圆阴影，随猫的水平位置移动；帧本身只含猫本体。

## 导出

| 项 | 值 |
| --- | --- |
| 格式 | PNG（RGBA，8 位/通道）；不用 GIF/APNG/WebP/JPEG |
| 尺寸 | 400×400（2×，页面 200 DIP） |
| 目录 | `src/JiuMi/Assets/MyJiuMi/<state>/`，状态名小写连字符：`lying-idle` / `blink` / `react` / `drag` / `sleep-in` / `sleep` / `wake` / `stretch` / `walk` |
| 文件名 | 两位序号，从 `00.png` 开始；按播放顺序编号 |
| 清单 | 由 `MyJiuMiAnimationCatalog` 定义帧序与时长；导出时同时给出「状态 → 帧数 → 时长」表 |
| 源文件/原图 | ImageGen 原图与导出 PNG 进 git；方向稿在 `docs/images/pet/direction-117/`，最终帧原图在 `docs/images/pet/final-121/`（走路源视频 `walk-source.mp4`）；临时试稿、废稿、带水印参考图不进 git；不再要求 SVG/Krita/PSD/AI 矢量源 |
| 体积 | 54 帧导出约 4.5 MB；6 张原图 + 4.1 MB 参考视频约 10.3 MB（不进应用包） |

- 导出前删除隐藏图层、背景、参考线、文字；只保留猫本体。
- 每帧独立 PNG，不用雪碧图；Avalonia 侧按状态按需加载。
- 线宽、色板与眼睛版本已按 #117 方向稿冻结，不再同时维护多套；#121 只按冻结稿出帧。

## 可读性检查

- 在 **200 DIP** 下看：脸、耳朵、眼睛、白口鼻/胸口/白爪和尾巴仍可辨认；轮廓不糊成一团。
- 浅色与深色页面背景各看一次：深棕轮廓能分离深色背景，白色块不发灰；透明边缘无黑边/白边。
- 若描边在深色背景上分离不足，优先在导出阶段加粗描边，不改已确认稿的配色与比例。
- 100% 与 200% 文本缩放各看一次：猫保持约 200 DIP，页面由内容岛滚动承接，不裁切。
- 看脸部特写确认：眼睛不是圆点、没有正面瞪视、眼睑与虹膜层次清楚；整体不再「诡异」。

## 审核门

1. **方向稿**：owner 看后不再觉得「诡异」；眼睛、比例、轮廓符合 #117 的描边插画气质。
2. **一致性**：趴/走/睡/起身/特写是同一角色、同一线宽与调色板；走路头身比自然，不滑步。
3. **页面尺寸**：200 DIP 下可读；浅/深色无黑边/白边；透明边缘干净。
4. **原创性**：无参考图水印或复刻痕迹；无写实毛发/AI 质感。
5. **冻结**：owner 选定方向后，帧数/时长/导出尺寸写进计划，交给 #121 出最终资源；最终资源通过后才进入 #119/#120 的页面集成。
