# ADR-0007 世界时钟节假日：Nager.Date、缓存与失败降级

- 状态：已接受
- 日期：2026-10-28
- 来源：#53；ADR-0008 定下地点的粒度与本地日历

## 背景

世界工作时间要把法定假日从工作窗口里剔除，并且不计入重叠。假日是这张工具页唯一需要联网的数据：目录、代表时区与工作周都内置，时区规则来自系统 `TimeZoneInfo`。

网络不可用、第三方服务不可用、服务不覆盖某个国家/年份，都是已知情况。工具必须仍然可用，且不能用全局 InfoBar 打断其他页面。

## 决策

1. **数据源**：Nager.Date，`GET /api/v3/PublicHolidays/{year}/{countryCode}`，按国家/年取。第三方聚合服务，不承诺 100% 覆盖。
2. **请求**：走系统代理；5 秒超时；失败重试一次；可取消。同一国家/年一次。
3. **缓存**：设置同根目录 `cache/holidays/{国家码}-{年}.json`，TTL 7 天；原子写；写失败不影响本次会话。
4. **成功**：覆盖该国家/年缓存；本次会话使用新数据。
5. **失败**：有缓存用缓存；无缓存在该地点的行内与页脚提示，并提供重试；不弹全局 InfoBar；记 Warning 日志。
6. **无数据 != 失败**：404 或空数组视为「该国家/年份无假日数据」，不重试、不提示失败，只记 Debug；原因是 Nager.Date 的覆盖范围有限，把不支持的国家当成网络故障会让用户反复重试。
7. **开关**：设置页「数据与联网」默认开。关闭后不发起任何请求；已有缓存仍可读，过期缓存不再刷新。
8. **判定**：假日按地点本地日期判定，优先于周末与工作窗口；假日整日不计入重叠。国家条目用代表时区的本地日期，城市条目用城市时区。
9. **不新增 `Error.*` 键**：时区/假日不可用是状态文案（`Tool.WorldClock.*`）；只有 Warning 及以上的日志事件。

## 为什么是 Nager.Date

- 免费、无需密钥、按国家/年返回 JSON，正好匹配「取某国某年的法定假日」。
- 不引入账号、配额与 OAuth；首版没有后端，第三方聚合是唯一现实选择。
- 覆盖率有限（约 110 个国家/地区），所以第 6 条把「无数据」与「请求失败」分开；这是这个数据源的必要配套，不是额外功能。

换源的成本被限制在 `IHolidayProvider` 实现与缓存文件格式：缓存键仍是「国家码 + 年 + 日期集合」，换源不需要改网格、地点或设置。

## 为什么缓存放在设置同根目录

设置位置已经由启动探针确定（exe `config\` → `%AppData%\JiuMi\` → 仅内存）。假日缓存与设置同根，跟随同一套可写性与回退规则；不另建缓存根，也不在程序目录写。

TTL 取 7 天：法定假日一年一变，7 天足够新鲜；每天启动都请求会让离线/弱网启动路径变长。

## 为什么失败不弹 InfoBar

假日是增强信息，不是工具的主路径。断网时用户仍要看看板与规划；用全局 InfoBar 抢占页面会打断「现在谁在上班」这个主问题。行内提示 + 页脚说明 + 重试按钮，范围限定在这一个地点/这一年，符合 #53 的降级口径。

## 备选与取舍

| 备选 | 为什么没选 |
| --- | --- |
| 运行期拉官方日历（各国政府站点） | 没有统一接口与格式，等于自建聚合器 |
| 把假日内置进应用 | 每年要发版；错过更新时结果错误且无提示 |
| 请求失败即弹 InfoBar | 断网时打断主路径；假日本身不是阻断级信息 |
| 404 也走失败重试 | 不支持的国家会永远提示失败，用户无法消除 |
| 缓存永不失效 | 假日调整/补假无法生效 |
| 关闭开关后连缓存也不读 | 用户只是不想联网，不是想丢掉已有数据；读缓存不产生请求 |

## 后果

正面：

- 节假日不阻塞工具主路径；离线时仍可用缓存或内置空集。
- 数据源可替换，缓存与 UI 不受影响。
- 「无数据」与「失败」分开，避免对不支持的国家反复重试。

负面（明确接受的代价）：

- 依赖第三方聚合服务的可用性与覆盖率；不覆盖的国家没有假日态。
- 每个国家/年一个请求；地点跨多国时首轮会有多个请求（并发上限与取消由实现保证）。
- 缓存目录与设置同根，用户清理配置会一并清掉假日缓存。

中性：

- 时区规则仍来自系统，不随假日数据更新。
- 假日覆盖周末与工作窗口，不改变「假日 > 周末 > 工作中 > 已下班」的优先级。

## 不在本 ADR 内

- 目录（国家/城市/工时）的粒度、内置快照与在线更新：见 [ADR-0008](./0008-world-clock-catalog.md) 与后续在线更新票。
- 时区不可用的降级：见 #53 与 `docs/ui-spec.md`。
- 假日的手动编辑、每城午休、法定工时上限：明确不做。
